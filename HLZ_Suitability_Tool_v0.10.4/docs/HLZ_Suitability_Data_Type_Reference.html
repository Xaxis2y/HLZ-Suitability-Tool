The tool reads shapes and numbers, not the ground. It does not read imagery, soil, ownership or live weather. Files in 06_Reference of the data folder are only kept for you to look at.

Latitude/longitude rasters (new in v0.9.0)

A raster in degrees is projected on the fly to the UTM zone of its centre, bilinear, with square cells of about the same ground size. The datum is kept where a UTM definition exists (NAD83 UTM zones 1 to 23 north when the source is NAD83; otherwise WGS 84 UTM). Latitudes beyond 80 S and 84 N have no UTM zone and are refused. In ArcGIS Pro the projected copy is written to HLZ_Projected.gdb in the run folder (named with a short hash, so a resumed run reuses it). Turn it off with Project a latitude/longitude DTM or DSM to UTM automatically (Advanced) or --no-auto-reproject. An area of interest given by bounding box on the command line must then use the UTM coordinates named in the log.

Exclusion areas: polygons, lines and points

Places that look like good ground in elevation data but are not. A touchdown point may never overlap them. Polygon, line and point layers can be mixed in the same field.

GeometryTypical useHow it is usedSetting
Polygon / multipolygonLakes, ponds, reservoirs, wide rivers, wetlands, built-up land, restricted areasFilled; a touchdown point may not touch it; the cleared ring is annotated when it touchesnone
PolylineRivers, streams, canals, shorelines, power lines, roadsWidened to a strip, half on each sideWidth given to exclusion LINES: 0 to 500 m, default 10 m. --line-width
Point / multipoint (v0.7.0)A crane, a pole, a known hazardBecomes a diskRadius given to exclusion POINTS: 0 to 500 m, default 10 m. --point-radius. With 0 only the cell holding the point is marked
FormatArcGIS ProCommand lineNotes
ShapefileYesNo (convert to GeoJSON)Needs its .prj; the audit warns when it is missing
GeoPackage / geodatabase feature classYesNoChoose the feature class
GeoJSONYes (as a layer)YesCoordinate system given by --exclude-crs (default EPSG:4326)
  • Any coordinate system and any size: only the part near each tile is read.
  • A lake drawn as a closed line excludes only the strip along the shore. Use the polygon.
  • In the data folder, 02_Hydrology accepts polygons and lines; 03_Exclusions also accepts points.
  • The line width and point radius are part of the inputs compared when an unfinished run is resumed.
  • A layer that does not overlap the DTM excludes nothing, and the dialog says so.

Obstacle lists: towers, masts, wires, buildings

Heights are above ground level (AGL), not above sea level. The tool adds them to the surface and tests every approach sector against them exactly. Public obstacle data is never complete: an obstacle that is not listed is not seen.

FormatExtensionsWhat is readHeights
FAA Digital Obstacle File.datFixed-width DOF records; dismantled records skipped; position as degrees-minutes-secondsAlways feet AGL. United States and territories only
CSV / text list.csv, .txtOne row per obstacle with latitude and longitude columns (WGS84)From the height column; see names below
GeoJSON.geojson, .jsonPoints, lines and polygons (WGS84), including OpenStreetMap exports (man_made=mast, tower, power=line, building)height tag, or building:levels x 3 m
GIS layershapefile, GeoPackage, geodatabase feature classPoints, lines or polygons, any coordinate systemFrom a height field

GIS layers work in ArcGIS Pro only. The command line reads the list files only.

Pass_Class: High at 25% or more of the area passing the ground test, Medium from 5%, Low above 0, otherwise None. Terr_Class: Flat when the mean slope is up to half the landing-slope limit, Moderate up to the limit, Steep above it.

Reasons in HLZ_Rejection_Summary.csv

Each analysed cell is counted once, under the first test it fails.

CodeReason
0Passes the ground test for any landing heading
1Passes the ground test only for an upslope landing
2Too little valid elevation data around the cell
3Ground too steep
4Ground too rough
5Too little surface-model (DSM) coverage to check obstacles
6Obstacle in the touchdown area taller than the limit
7Obstacle in the cleared ring taller than the limit
8Touchdown area would touch an exclusion area (water, wetland, ...)
9Too close to a listed obstacle (tower, mast, building, ...)

The CSV columns are Reason, Passed_ground_test, Cells, Percent_of_cells, Area_ha, followed by a second block Candidate step, Count (exact checks, rejected by the exact check, tile-seam duplicates, dropped for the minimum spacing, dropped by the candidate limit, candidates kept).
