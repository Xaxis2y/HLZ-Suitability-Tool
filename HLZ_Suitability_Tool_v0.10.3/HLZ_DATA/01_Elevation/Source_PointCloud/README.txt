01_Elevation\Source_PointCloud  -  Source point cloud (LAS/LAZ)  [OPTIONAL]
==============================================================================

WHAT GOES HERE
  LAS, LAZ, zLAS files or a LAS dataset (.lasd). They are listed but NOT read by the analysis.

WHY
  Keeps the source lidar next to the rasters made from it.

TIPS
  - Make the DTM with LAS Dataset To Raster using ground points (class 2), and the DSM using first returns.
  - Save the results into 01_Elevation\DTM and 01_Elevation\DSM.

Run '0. Set Up and Audit Data Folder' (ArcGIS Pro) or AUDIT_DATA_FOLDER.bat to check this folder.
