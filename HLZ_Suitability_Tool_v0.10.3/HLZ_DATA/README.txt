HLZ DATA FOLDER
==============================================================================
Put each input in its folder, then run the audit. It tells you what is missing, what is
wrong and how to fix it, and which files the analysis will use.

  01_Elevation\DTM                 REQUIRED     Bare-earth elevation (DTM)
  01_Elevation\DSM                 RECOMMENDED  Surface model (DSM)
  01_Elevation\Source_PointCloud   OPTIONAL     Source point cloud (LAS/LAZ)
  02_Hydrology                     RECOMMENDED  Hydrology (water polygons)
  03_Exclusions                    OPTIONAL     Other exclusion areas
  04_AOI                           OPTIONAL     Area of interest
  05_Search_Centres                OPTIONAL     Search centres
  06_Reference                     REFERENCE    Reference data
  07_Profiles                      OPTIONAL     Custom profiles
  08_Runs                          OUTPUT       Analysis runs (output)
  09_Audit                         OUTPUT       Audit reports (output)

STEPS
  1. Copy the DTM into 01_Elevation\DTM and the DSM into 01_Elevation\DSM (one raster each).
  2. Copy water polygons into 02_Hydrology (strongly recommended) and other no-landing
     polygons into 03_Exclusions.
  3. Optional: an area of interest polygon into 04_AOI, search points into 05_Search_Centres.
  4. Audit: ArcGIS Pro tool '0. Set Up and Audit Data Folder', or AUDIT_DATA_FOLDER.bat.
     The report is written to 09_Audit\HLZ_Data_Audit_latest.html.
  5. Analyse: in '1. Analyze HLZ Suitability' choose this folder in the first field
     ('HLZ data folder'). The DTM, DSM, exclusion layers, AOI and output folder are
     filled in for you.

Keep this folder on a local disk (not OneDrive/Dropbox) with a short path, e.g. C:\GIS\HLZ_DATA.
Nothing in this folder is ever moved or deleted by the tool.
