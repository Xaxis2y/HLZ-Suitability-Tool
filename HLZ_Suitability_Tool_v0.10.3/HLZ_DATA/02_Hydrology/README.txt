02_Hydrology  -  Hydrology (water polygons)  [RECOMMENDED]
==============================================================================

WHAT GOES HERE
  Polygon layers: shapefile (.shp), GeoJSON (.geojson), GeoPackage (.gpkg) or a file geodatabase (.gdb).

WHY
  Lakes, ponds, wide rivers and reservoirs. A touchdown point may never touch them. Without water polygons a lake is perfectly flat and smooth and can be rated as an excellent landing zone.

TIPS
  - Polygons only. River centre LINES cannot be used: buffer them to polygons first (Buffer tool).
  - Any coordinate system works; only the part near the analysis area is read.
  - Water layers can be old: still check candidates on recent imagery.

WHERE TO GET IT (check each licence)
  - Ontario Hydro Network (OHN) - Waterbody (Open Government Licence - Ontario)
  - NRCan National Hydrographic Network (NHN) / CanVec hydro features
  - USGS National Hydrography Dataset (NHD) / 3D Hydrography Program (3DHP)
  - OpenStreetMap water polygons
